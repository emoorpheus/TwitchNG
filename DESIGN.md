# Next-Gen UI (redesign, in progress)

Status: **in the build since pre-release 06**, on by default on top of the OLED preset (`html.ng-ui`; no NG UI without the
preset). Stage 1 done (design system, live grid, side menu, header) + part of stage 2 (switch pills, video / clip, category and
channel cards, history cards). Off: `localStorage.TWITCHNG_UI = '0'` or `TwitchNG.ui(false)`, then restart the app (main.js
measured the grid row steps with the other sizes). Plan and owner decisions: `ROADMAP.md` items 1-2.

Owner decisions (2026-11-05): font **Onest** (as "NG Sans"), icons **variant B: sharp corners** (Lucide, miter joins, stroke 2.5),
the Russian texts may be fixed freely (counted `main.js` patches in `build/build-app.mjs`, or the text layer in `ng-ui.js`).

## Rules

- Palette: Twitch `#9146FF`, Lavender `#BF94FF`, Snow `#F5F3FA`, secondary `#C9C3D6`, Mist `#8E87A2`, dim `#625C75`, Live `#FF3B4E`.
  **Canvas = true black `#000`** (the NG UI is the OLED preset's look, and the preset's rule holds: never more light than the
  classic look on any screen, `tests/app/twitchng.mjs` with pictures hidden; pre-release 06: home -12 %, side -46 %, settings -18 %).
  A faint static purple haze at the top (alpha .12) is the canvas' only light; picture placeholders are black with a 1 px line.
  Night `#08070D` stays the splash / intro backdrop.
- Type (1080p px): screen title 46 / 900, channel 32 / 700, stream title 25 / 400, meta 23 / 600 + 400, hints 20 / 600. No
  letter-spacing hacks, sentence case; sizes in `vh` in the CSS. Every upstream Roboto / Roboto-Bold text is NG Sans through
  `@font-face` remaps with `unicode-range` (other scripts keep the system fonts); keep `html.ng-ui .fa { font-family: icons }` -
  without it main.js re-appends its icon sheet after ours and the remap is lost.
- One bold thing per screen = focus: card lift 5 % + 4 px lavender ring + purple glow; menu row and switch pill = purple pill,
  current section = lavender. Static chrome (hints, clock, counter) dim: burn-in.
- Layout: grid rows keep the upstream steps (main.js scroll math caches them); vertical budget at 1080p: header band 93 px
  (opaque to 82 px), grids start below it (holder tops 8.6-9.4 %), two rows of live / video cards or posters must end above the
  screen edge with the 4th line of history cards included. 3 columns live / video, 5 posters, 6 channels.
- Card text lines are styled by classes from `ng-ui.js` (not by position): history cards add a line, upstream may add more.
- TV performance: animate transform / opacity only; the big shadow only on the focused card; no backdrop-filter; one text
  pass per animation frame over the changed cards only.
