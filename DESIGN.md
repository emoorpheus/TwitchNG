# Next-Gen UI (redesign, in progress)

Status: **concept, stage 1** (live grid + side menu), not wired into the build: the IPK still ships the upstream look + the OLED
preset (`brand/twitchng/web/twitchng.css`). Plan and owner decisions: `ROADMAP.md` items 1-2.

## Files

| File | What |
| --- | --- |
| `brand/twitchng/web/ng-ui.css` | tokens, NG Sans, live grid, header, side rail / menu (scoped to `html.ng-ui`) |
| `brand/twitchng/web/ng-ui.js` | sets `html.ng-ui`; card meta (viewers badge, `game · 7 ч 32 мин`, language chip), clock, hints, RU copy |
| `brand/twitchng/web/ng-icons.css` | GENERATED by `node tools/make-ng-icons.mjs`: Lucide SVGs as CSS masks over the upstream icon-font classes |
| `brand/twitchng/web/fonts/ng-sans-*.woff2` | GENERATED by `python3 tools/make-ng-fonts.py`: Source Sans 3 subset renamed "NG Sans" (OFL, `OFL-SourceSans3.md`) |
| `brand/twitchng/src/icons/lucide/` | vendored Lucide icons (ISC, `LICENSE`) |
| `tools/ui-lab.mjs` | runs a built IPK in Chromium (1920 x 1080, real API), injects CSS / JS / font sets, saves screenshots |

```sh
NG_LANG=ru_RU NG_LOCALE=ru-RU node tools/ui-lab.mjs <ipk> /tmp/lab \
  --css brand/twitchng/web/ng-ui.css,brand/twitchng/web/ng-icons.css --js brand/twitchng/web/ng-ui.js --screens home,home2,side,side2,side3
```

## Rules

- Palette: Night `#08070D` (splash backdrop), Ink `#14111F`, Haze `#1E1830`, Twitch `#9146FF`, Lavender `#BF94FF`, Snow `#F5F3FA`,
  Mist `#8E87A2`, Live `#FF3B4E`. Dark by default, a faint static purple haze at the top.
- Type (1080p px): screen title 46 / 900, channel 32 / 700, stream title 25 / 400, meta 23 / 600 + 400, hints 20 / 600. No
  letter-spacing hacks, sentence case; sizes in `vh` in the CSS.
- One bold thing per screen = focus: card lift 5 % + 4 px lavender ring + purple glow; menu row = purple pill, current section =
  lavender text. Static chrome (hints, clock, counter) dim: burn-in.
- Layout: grid rows keep the upstream 17 em steps (main.js scroll math); 3 columns, ~33 px gutters, ~85 px right margin.
- TV performance: animate transform / opacity only; the big shadow only on the focused card; no backdrop-filter.
